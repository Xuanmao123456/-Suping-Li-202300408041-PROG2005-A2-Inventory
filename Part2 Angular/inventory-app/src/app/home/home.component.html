Welcome to Angular Inventory Management System

This application is the Angular version of PROG2005 A2 Part1, developed for mobile and web systems programming. It implements all core functions of inventory management, complying with user-centered design principles and mobile privacy & security requirements.

Core Application Purpose

  • Manage inventory items with add, edit, delete, search and filter functions
  • Support responsive design for mobile and desktop devices
  • Implement strict data validation to ensure data integrity
  • Analyze and display privacy & security requirements for mobile inventory apps
  • Provide detailed help documentation and FAQs for users
